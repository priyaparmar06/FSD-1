# Student Expense Tracker

## Project Description

Student Expense Tracker is a web application developed to help students manage and track their daily expenses.

## Features

- Add new expenses
- View expense records
- Delete expenses
- Select expense category
- Store expenses in MongoDB
- React frontend
- Express.js backend
- REST API integration

## Technologies Used

- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Frontend

The frontend is developed using React.js and provides an interface for managing student expenses.

## Backend

The backend is developed using Node.js and Express.js and provides REST API endpoints for expense operations.

## Database

MongoDB is used to store expense records.

## API Endpoints

- GET /api/expenses
- POST /api/expenses
- GET /api/expenses/:id
- PUT /api/expenses/:id
- DELETE /api/expenses/:id
